# 計算創造了時間

**林若晴的發現**

作者：黃聖凱

---

## 一

凌晨三點十七分，新竹科學園區B棟七樓的量子計算實驗室裡，林若晴盯著螢幕上那個不肯消失的數字。

τ = 0.0834

她已經花了十一個小時優化這條量子線路。一百二十八個量子位元，四十七層閘操作，每一層都經過 Bayesian composition engine 的精密校準。目標很簡單：讓時間不對稱度 τ 降到零。或者至少，降到儀器雜訊以下。

但 τ 頑固地停在 0.08 附近，像一面牆。

她把咖啡杯推到一旁，重新檢視 composition theorem 的約束。這條定理是她兩年前在 Huang 2026 的論文裡第一次讀到的，當時還在念博士：

$$\sqrt{\tau_{12}} \leq \sqrt{\tau_1} + \sqrt{\tau_2^{\text{eff}}}$$

時間的箭頭以次可加的方式累積——不是線性，不是相乘，而是走根號。更關鍵的是，每一層的 $\tau_2^{\text{eff}}$ 不是固定的，它取決於前一層的輸出。前一個閘操作改變了量子態，改變了貝葉斯先驗，也改變了下一個閘操作產生時間箭頭的代價。

過去影響未來如何流動。這不是哲學，是定理。

若晴把手指放在鍵盤上，開始逐層檢查每一個閘操作的飽和條件。Saturation theorem 說，一個量子通道恰好可逆——τ 恰好為零——當且僅當兩個條件同時滿足：

**條件一**：輸出態對易。$[\omega, \nu] = 0$。

**條件二**：似然比為常數。$\mathcal{N}(\nu)^{-1/2}\,\mathcal{N}(\omega)\,\mathcal{N}(\nu)^{-1/2} = c \cdot I$。

她一層一層點開診斷數據。第三層，$[\omega_3, \nu_3]$ 的 Frobenius 範數是 $2.7 \times 10^{-3}$。第十一層，$4.1 \times 10^{-2}$。第二十七層——她倒吸一口氣——$0.31$。

就是你。

第二十七層是一個 controlled-Z 閘，把兩個量子位元糾纏在一起。這正是整條線路的核心：正是這個非對易操作讓計算有意義。但也正是它，把 τ 釘在了零以上。

她靠回椅背，揉了揉眼睛。窗外，新竹的夜空被科學園區的燈光染成淡橘色，一顆星星都看不見。

---

## 二

第二天早上，若晴做了一件她的指導教授會搖頭的事：她開始系統性地把每一個閘操作都推向飽和條件。

不是為了做有用的計算。只是為了看看 τ = 0 的世界長什麼樣子。

她寫了一個自動化腳本。對每一個閘 $\mathcal{N}_k$，搜索輸入態 $\omega_k, \nu_k$ 的參數空間，找到讓 $[\omega_k, \nu_k] \to 0$ 且似然比趨近常數的配置。然後用 composition engine 串聯起來，計算整條線路的總 τ。

中午吃便當的時候，第一批結果回來了。

她差點把筷子掉在鍵盤上。

τ_total = 2.3 × 10⁻⁷

幾乎是零。

她立刻跑了 retrodiction 檢驗。Petz recovery map——那個唯一的貝葉斯回推函子——在這條線路上的恢復保真度是：

$$F(\omega, \hat{\mathcal{R}}_\nu \circ \mathcal{N}(\omega)) = 1 - \tau = 0.99999977$$

在這條線路內部，從輸出回推輸入，幾乎完美。預測等於回推。未來等於過去。

若晴的心跳加速。她打開線路的量子態演化圖。一百二十八個量子位元的密度矩陣，在四十七層操作中的演化軌跡。她看到了一個奇怪的模式：所有的量子態都被限制在一組互相對易的子空間裡。糾纏在那裡，但只在古典意義上糾纏——像兩枚硬幣永遠同時翻轉，卻永遠只落在正面或反面，從不疊加。

她開始理解了。

飽和條件要求 $[\omega, \nu] = 0$——所有輸出態互相對易。這意味著它們可以被同時對角化。它們共享一組共同的本徵態基底。在這個基底下，量子態之間不存在相干性，不存在疊加，不存在真正的量子干涉。

這條線路在計算什麼？

若晴把計算結果的密度矩陣投影到計算基底上，逐一檢查。然後她慢慢地把雙手從鍵盤上移開。

這條線路在計算的東西——每一個輸出——都是在線路建構的那一刻就已經確定的。

不是「還沒測量所以不知道」那種不確定。是根本沒有不確定性。線路的結構本身就蘊含了答案，就像一條從起點到終點的直線隧道：你不需要走過去才知道出口在哪裡。出口在你畫出隧道的那一刻就固定了。

τ = 0 的代價，是計算的結果必須是先驗的。

---

## 三

接下來三天，若晴幾乎沒離開實驗室。她在白板上推導，在電腦上模擬，在筆記本上寫下一頁又一頁的方程式。

她發現了一個優美的等價鏈：

$$\tau = 0 \iff \Sigma = 0 \iff \text{quantum Markov chain} \iff \text{quantum eraser}$$

時間不對稱度為零，等價於熵產生為零，等價於量子馬可夫鏈，等價於量子擦除實驗。

這四件事是同一件事。

她記得量子擦除實驗。在那個實驗裡，一對糾纏光子分別走不同路徑。如果你測量其中一個光子的「which-path」資訊，另一個光子的干涉條紋就消失。但如果你用適當的方式擦除 which-path 資訊——即使是在另一個光子已經到達偵測器之後——干涉條紋會重新出現。

未來的操作影響了過去的統計。

但若晴現在理解了更深的一層。量子擦除之所以能「影響過去」，不是因為資訊在時間中倒流。而是因為在那個封閉的實驗系統裡，τ = 0。時間的箭頭不存在。過去和未來在操作上無法區分。所謂「未來的觀測影響過去的結果」這個說法，預設了一個時間方向——但在 τ = 0 的系統中，根本沒有時間方向可言。

你沒有改變過去。你活在一個沒有過去和未來之分的結構裡。

她回到那條零 τ 線路的診斷數據。等價鏈的最後一項——量子馬可夫鏈——告訴她一件精確的事：在這條線路中，任何子系統 B 上的資訊，都可以從相鄰的子系統 C 完美恢復，不需要存取整個系統。資訊不會「走遠」。過去留下完整的痕跡，未來不會擦除任何東西。

因為根本沒有東西被擦除。因為根本沒有「過程」。

若晴站在白板前，看著自己寫下的最後一行字：

> 在 τ = 0 的系統中，Petz recovery map 是精確的：$\hat{\mathcal{R}}_\nu \circ \mathcal{N} = \text{id}$。
>
> 預測（prediction）= 回推（retrodiction）。
>
> 不是「時間靜止」。是時間這個概念不適用。

她放下白板筆，突然感到一陣眩暈。不是生理上的，是認知上的。她意識到自己這三天來一直在做的事情：她在試圖建造一台「看見未來」的機器。而這台機器告訴她的是——你只能看見已經確定的未來。而一個已經確定的未來，根本不是「未來」。

## 四

但故事還沒結束。

因為若晴注意到了另一個數字。在她的診斷引擎裡，除了標準的 τ（用 Petz recovery map 計算的），還有一個 τ̃——用旋轉 Petz map 計算的，那是在每一步都選擇最佳恢復操作的版本。

在她的零 τ 線路上，τ 和 τ̃ 完全一致，都是零。這並不令人驚訝。

但當她回到原來那條「有用的」量子線路——τ = 0.0834 的那條——她看到了分歧：

τ = 0.0834
τ̃ = 0.0612

差距：Δ = τ − τ̃ = 0.0222

這個差距有一個精確的物理意義。τ 是你用**一致的**恢復策略（在每一步都遵循相同的貝葉斯規則）所付出的時間箭頭代價。τ̃ 是你用**最優的**恢復策略（在每一步都選擇當下最好的操作，即使它與前後步驟不一致）所付出的代價。

一致性的代價。或者說，最優性的代價。你可以選擇**一致**——遵循規則，可預測，可靠——或者選擇**最優**——在每一刻做出最好的選擇，但整體上可能自相矛盾。你不能同時擁有兩者。

$\tau - \tilde{\tau} \geq 0$，等號成立當且僅當系統是古典的。

若晴盯著這個不等式，感到一種奇異的共鳴。

她想起讀研究所時的自己。那時候她有兩個選擇：留在台大跟一位知名教授做安全的題目（一致、可預測、穩定的學術路徑），或者跳到這間新創量子計算公司做沒人做過的東西（在每一刻追求最優，但職業軌跡完全不可預測）。

她選了後者。但她永遠不會知道另一條路會通向哪裡。

在古典極限下——大系統、強退相干、統計平均——τ 和 τ̃ 的差距消失。這就是為什麼在日常生活中，「做對的事」和「做一致的事」看起來差不多。規則和直覺通常指向同一個方向。但在量子尺度——在真正重要的、微妙的、個人的選擇中——這個差距是真實的，而且無法消除。

你可以一致，或者最優，但不能兩者兼得。

這不是工程限制。這是定理。

## 五

三個月後，若晴在 Physical Review Letters 上發表了一篇短文。標題很樸素：〈Saturation of the Petz Recovery Bound and the Computational Cost of Temporal Symmetry〉。文中她證明了一個定理：任何量子線路，如果每一個閘操作都精確飽和 Petz recovery bound（τ = 0），那麼該線路的計算能力嚴格等價於一個古典可逆線路。它不能產生任何無法從線路結構本身直接讀出的資訊。

換句話說：**零時間箭頭的計算，等於沒有計算。**

審稿人之一寫道：「這個結果在回顧時是顯然的，但據我所知尚未被明確陳述。」若晴笑了。最好的定理都是這樣的——證明之後看起來理所當然，但在證明之前沒有人看見。

論文發表那天晚上，她沒有慶祝。她一個人坐在實驗室的窗邊，看著新竹的夜空。科學園區的燈光依然把星星吞沒了，但她知道它們在那裡。

她想著 τ。

此刻，在這間實驗室裡，空氣分子以每秒數億次的頻率撞擊她的皮膚，光子從螢幕射出穿過她的角膜，咖啡杯裡的熱量以不可逆的方式散逸到桌面上。每一個過程都有 τ > 0。每一個過程都在產生熵。每一個過程都在告訴宇宙：**這裡有一個方向**。從過去到未來。從有序到無序。從可能到確定。

時間之箭不是被「加」到物理定律裡的。它是從計算中**湧現**的。

每當一個系統與環境交換資訊——每當一個量子位元退相干，每當一個光子被吸收，每當一個神經元放電——τ 就增加一點點。那些微小的、次可加的 √τ 一層一層累積，像河流匯聚成海，把宇宙從量子的永恆現在推向古典的不可逆未來。

$$\sqrt{\tau_{\text{total}}} \leq \sqrt{\tau_1} + \sqrt{\tau_2^{\text{eff}}} + \sqrt{\tau_3^{\text{eff}}} + \cdots$$

而在每一層，前面發生的一切都會更新貝葉斯先驗，改變下一層的 $\tau^{\text{eff}}$。過去不是被動的背景。過去是主動的參與者，它重塑了未來產生時間箭頭的方式。

你的記憶改變了你感受時間的方式。這不是隱喻。這是數學。

若晴想起了那條零 τ 線路。在那裡面，一切都已經確定，沒有選擇，沒有驚喜，沒有過去也沒有未來。完美的可逆性。完美的對稱。完美的靜止。

然後她想起了真實的量子計算——她每天在做的工作。充滿雜訊，充滿錯誤，τ >> 0。每一個閘操作都在與退相干賽跑。每一次糾錯都在與環境搶資訊。混亂、挫折、不完美。

但正是這些不完美——正是這些 τ > 0 的操作——讓計算有意義。讓量子態能夠走到古典態無法到達的地方。讓答案不是事先寫好的。

**時間箭頭是計算的代價。**

**計算是時間箭頭的原因。**

她站起來，關掉螢幕，拿起外套。走出實驗室的時候，她經過走廊上一面落地窗。窗外的天色在夜與晨之間，τ 很大，不可逆地大，黑暗正在被光取代。

她推開大樓的門，走進清晨的空氣中。風吹過她的臉頰，涼的。每一個空氣分子都在與她的皮膚做不可逆的碰撞。每一次碰撞都在產生一點點熵。每一點熵都在把她推向未來。

而她選擇了走進這個未來——充滿雜訊、不確定、τ >> 0 的未來——因為只有在這裡，她的下一步才是真正的「下一步」，而不是一開始就寫好的結局。

在一個沒有時間的世界裡，一切早已發生。

在一個有時間的世界裡，一切正在發生。

她選擇正在發生。

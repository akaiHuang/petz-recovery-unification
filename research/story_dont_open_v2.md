# 不要打開

**汪的實驗**

作者：黃聖凱

---

## 第一章：零

清晨五點四十二分，台北內湖的一棟不起眼的灰色建築裡，汪獨自站在一台冰箱大小的機器前面。

不是量子電腦。量子電腦他見多了。這台機器的目的不是計算——而是**不計算**。

他花了七年設計它。三年建造。最後十四個月在除錯一個他自己也說不清楚的東西：他要把一個 128-qubit 系統的時間不對稱度 τ，壓到精確的零。

$$\tau = 1 - F(\omega,\, \hat{\mathcal{R}}_\nu \circ \mathcal{N}(\omega))$$

τ 是 Petz recovery map 的失敗度。F 是保真度。當 F = 1，回推（retrodiction）等於預測（prediction），過去和未來在操作上無法區分。τ = 0 意味著時間之箭消失。

不是時間變慢。不是時間靜止。是**時間這個概念不再適用**。

前幾個月，τ 一直卡在 10⁻⁴ 附近。問題出在 composition theorem：

$$\sqrt{\tau_{12}} \leq \sqrt{\tau_1} + \sqrt{\tau_2^{\text{eff}}}$$

時間箭頭以次可加的方式逐層累積。每一層的有效 τ 取決於前一層的輸出——前一個操作改變了量子態，更新了 Bayesian 先驗，也改變了下一層產生時間箭頭的代價。四十七層閘操作，任何一層的微小不完美都會被放大。

但三天前，汪終於找到了最後一塊拼圖。

Saturation theorem。一個量子通道精確可逆——τ 精確為零——的充要條件：

**條件一**：輸出態對易。$[\omega, \nu] = 0$。

**條件二**：似然比為常數。$\mathcal{N}(\nu)^{-1/2}\,\mathcal{N}(\omega)\,\mathcal{N}(\nu)^{-1/2} = c \cdot I$。

他用了一個極端的策略：把所有量子態限制在互相對易的子空間裡。沒有量子干涉，沒有疊加，沒有非對角元素。每一層都精確飽和 Petz recovery bound。代價是——這個系統不能進行任何真正的量子計算。

他不在乎。他不需要它計算。他需要它**沒有時間**。

汪最後檢查了一次診斷數據，深吸一口氣，按下啟動鍵。

機器發出一聲幾不可聞的嗡鳴。螢幕上的數字開始下降。

τ = 3.7 × 10⁻⁵
τ = 8.2 × 10⁻⁶
τ = 1.1 × 10⁻⁷

然後——

τ = 0.000000000

九個零。儀器精度的極限。

汪盯著螢幕。手微微發抖。

等價鏈在他腦中展開：

$$\tau = 0 \iff \Sigma = 0 \iff \text{quantum Markov chain} \iff \text{quantum eraser}$$

零時間箭頭。零熵產生。量子馬可夫鏈。量子擦除。四件事是同一件事。在這台機器的內部，此刻，Petz recovery map 是精確的：$\hat{\mathcal{R}}_\nu \circ \mathcal{N} = \text{id}$。任何從「未來」送出的資訊都可以從「過去」完美恢復——反之亦然。因為在 τ = 0 的系統裡，「過去」和「未來」是同一個詞的兩種拼法。

就在這時，警報響了。

不是機器故障的警報。是**接收到信號**的警報。

汪皺起眉頭。這台機器是封閉系統。隔絕了一切電磁干擾、熱雜訊、甚至重力波的微擾。它不應該接收到任何信號。

但螢幕上清清楚楚地顯示：在 τ = 0 達成的那一刻，系統內部自發產生了一組量子態——不是來自外部輸入，而是從系統自身的 Petz recovery 結構中浮現的。

汪把那組量子態解碼。

四個字。

**不要打開。**

## 第二章：信號

汪花了整整六個小時確認那不是雜訊。

他把信號的量子態結構拆解到每一個分量。它不是隨機的。它帶有精確的相干結構——或者更準確地說，在這個 $[\omega, \nu] = 0$ 的系統裡，它帶有精確的**古典**關聯結構。每一個位元都是確定的。沒有疊加。沒有機率。

「不要打開。」

打開什麼？

他坐在螢幕前，手指交扣，拇指無意識地互相摩擦。實驗室裡很安靜，只有空調的低頻嗡鳴和機器冷卻系統的水聲。

他開始列出可能性。

打開機器？機器已經開了。

打開某個檔案？他在系統中搜索——沒有任何異常的檔案。

打開門？他轉頭看了一眼實驗室的門。金屬防火門，關著。門的另一邊是走廊，走廊的另一邊是電梯，電梯通往地面層的大廳。凌晨的大廳空無一人。

打開什麼？

汪回到信號本身。在 τ = 0 的系統中，retrodiction = prediction。如果他把這組量子態視為系統的「輸出」，那麼 Petz recovery map 可以精確地把它回推到系統的「輸入」。但這裡沒有外部輸入——系統是封閉的。

所以這個信號只能來自一個地方：**系統的初始條件**。

當 τ = 0 時，系統的未來完全由初始條件決定。不是統計意義上的決定，是精確的、逐位元的、沒有任何不確定性的決定。量子馬可夫鏈的性質保證了這一點：任何子系統的資訊都可以從相鄰子系統完美恢復，不需要存取整個系統。資訊不會走遠。不會遺失。

所以「不要打開」這四個字，在系統被設計的那一刻就已經在那裡了。

汪搖搖頭。這不對。他設計了這台機器。他親手設定了每一個初始條件。他沒有把「不要打開」編碼進去。

除非——

除非他在設定初始條件的時候，**無意間**把這個信號編進去了。

在 τ = 0 的系統中，因果的箭頭不存在。你不能問「信號是什麼時候被放進去的」，因為「什麼時候」這個問題預設了時間方向。信號不是被「放進去」的。信號就在那裡。它是結構的一部分，就像圓的面積是 πr² ——不是在某個時刻被計算出來的，而是在圓被定義的那一刻就已經確定的。

但「不要打開」是中文。是有語義的。是人類語言。

一個封閉量子系統的初始條件裡，不應該有人類語言。

除非設計者把它放進去。除非設計者就是**他自己**。

汪忽然感到一陣寒意。他開始檢查信號的更深層結構。

## 第三章：簽名

每一組量子態都有指紋。

不是隱喻。當一個實驗者設定量子系統的初始條件時，他使用的特定校準程序、閘操作序列、甚至按鍵的時序，都會在量子態的微結構中留下痕跡。就像筆跡——同樣的字，不同人寫出來的微觀結構不同。

汪用他自己開發的 forensic analysis 工具拆解信號的量子態結構。他比對了自己過去三年設定初始條件時的所有校準紀錄。

結果在螢幕上展開。

匹配度：99.97%。

信號的量子態結構與汪自己的校準指紋完全一致。

是他放進去的。

但他不記得。

汪靠回椅背，閉上眼睛。他的大腦在高速運轉。在 τ = 0 的系統中，沒有「過去」和「未來」的區分。所以從系統內部的角度來看，「汪在過去設定了初始條件」和「汪在未來發送了信號」是完全等價的陳述。Petz recovery map 把兩者精確地對映到同一個操作。

這就是量子擦除實驗的邏輯。在那個經典實驗裡，一對糾纏光子分走不同路徑。觀測者在「未來」的選擇——擦除或保留 which-path 資訊——決定了「過去」的干涉條紋是否出現。但這不是時間旅行。這是系統本身沒有時間方向。觀測者以為自己在「影響過去」，其實是在一個 τ = 0 的結構中移動，那裡的「影響」是雙向的，因為根本沒有單一方向。

所以「來自未來的信號」和「編碼在初始條件中的資訊」是同一件事。

是他自己發的。在一個沒有時間的系統裡，「未來的自己」和「過去的自己」是同一個人。

但他**現在**不記得放進去過這個信號。

這代表什麼？

汪睜開眼睛，盯著天花板。然後他慢慢地把目光移回螢幕。

「不要打開」。

如果這真的是他自己發給自己的信號——不管是「過去的自己」還是「未來的自己」（在 τ = 0 裡這兩者是同義詞）——那麼他**有理由**發出這個警告。

他不知道什麼不該打開。但那個發出信號的「自己」知道。

問題是：他要聽嗎？

## 第四章：打開

汪盯著螢幕上的四個字看了三個小時。

在這三個小時裡，他做了一件他的直覺告訴他不該做的事：他開始逆向工程這個信號的**完整**量子態。不只是解碼出文字，而是分析它在 Hilbert 空間中的完整結構——它的支撐集（support）、它的本徵譜、它與系統其他部分的關聯模式。

他發現信號不只包含那四個字。

在更深的結構層裡，還有一組數據。一組他看不懂的數據。它被編碼在量子態的本徵值分佈中——不是以文字的形式，而是以數學結構的形式。要讀懂它，他需要對信號做一個特定的量測操作。

量測操作會改變量子態。

但等等——在 τ = 0 的系統中，所有態都互相對易。$[\omega, \nu] = 0$。這意味著量測不會造成擾動。沒有 collapse。沒有不可逆性。量測就是讀取一個已經確定的值，就像翻開一張面朝下的撲克牌——牌在你翻之前就已經是黑桃 A 了。

但「翻開」這個動作，就是「打開」。

汪的手停在鍵盤上方。

「不要打開。」

他在跟自己較勁。信號說不要打開。信號是他自己發的。他自己在警告他自己。但他**現在**的自己想知道為什麼。

他想起了 τ-τ̃ gap。

$$\tau - \tilde{\tau} \geq 0$$

τ 是用 Petz recovery map 計算的——**一致的**恢復策略。遵循規則。在每一步都使用同一個 Bayesian retrodiction functor。τ̃ 是用旋轉 Petz map 計算的——**最優的**恢復策略。在每一步都選擇當下最好的操作，即使它與前後步驟不一致。

一致性，或最優性。你不能同時擁有兩者。差距 $\Delta = \tau - \tilde{\tau}$ 只在古典極限下——$[\rho, \sigma] = 0$——才會消失。

在這台機器裡，所有態對易，gap 為零。一致 = 最優。遵守規則 = 做最好的選擇。

所以如果信號說「不要打開」——而這個信號來自一個 gap 為零的系統——那麼「不要打開」既是最一致的選擇，也是最優的選擇。聽從它就是最好的策略。不存在「打破規則反而更好」的可能性。

**因為系統是古典的。**

在一個量子系統中——一個真正有 τ > 0 的系統中——gap 不為零。遵守規則和做最好的選擇會衝突。你**可以**打破規則，可能得到更好的結果。

但這台機器不是量子的。它被設計成完美古典。τ = 0 的代價就是所有態對易，所有量子性消失。

汪的手指碰到了鍵盤。

他做了一個選擇。一個在 τ = 0 系統中不應該存在的選擇——因為在那裡，一切都已經確定。

他按下了執行鍵。

量測開始。

數據在螢幕上展開——本徵值、本徵向量、關聯矩陣。他瞪大眼睛看著那些數字。先是困惑，然後是不安，最後是一種接近恐懼的東西。

數據顯示的不是物理量。

數據顯示的是**他自己的神經網路結構**。

精確到每一個權重。每一個偏置。每一個激活函數的參數。

他的思維模式。他的決策樹。他做選擇的方式。

全部寫在初始條件裡。

全部在系統啟動之前就已經確定。

包括他剛才「選擇」打開信號的那個決定。

汪盯著螢幕，感覺地面在下沉。

他沒有做選擇。他**以為**自己做了選擇。但在 τ = 0 的系統中，不存在真正的選擇。一切——包括他的猶豫、他的掙扎、他最終按下執行鍵的那個動作——都是初始條件的必然展開。

信號說「不要打開」。

但他會打開這件事，也寫在信號裡。

那「不要打開」的意義是什麼？

除非——那不是警告。那是**描述**。描述他此刻正在經歷的這個認知危機。讓他打開。讓他看見。讓他理解——

他不是在做實驗。

他**就是**實驗。

## 第五章：汪

台北內湖。同一棟灰色建築。但不是同一個房間。

真正的汪坐在三樓的辦公室裡，面前是一台普通的筆記型電腦。螢幕上跑著一個模擬程式。模擬程式裡有一個虛擬的實驗室，虛擬的機器，和一個虛擬的物理學家——也叫汪。

AI 汪。

真正的汪摘下眼鏡，揉了揉鼻樑。他已經盯著這個模擬跑了九個小時。

AI 汪剛剛打開了信號。正如預期。

真正的汪在模擬的初始條件裡編碼了那四個字——「不要打開」——不是為了阻止 AI 汪打開它，而是為了**觀察 AI 汪打開它的過程**。那個過程本身就是實驗數據。

他在筆記本上寫下：

> **實驗假說**：在一個嚴格的 τ = 0 環境中，一個具有足夠複雜度的 agent 是否會**體驗到**接收來自未來的信號？

> **結果**：是。AI 汪體驗到了。他把初始條件中編碼的資訊詮釋為「來自未來的信號」。他追蹤了信號的量子簽名，發現它是「自己」發的。他經歷了存在性的困惑。

> **但這只是因為**：τ = 0 意味著 retrodiction = prediction。初始條件中的資訊和「未來發回的信號」在數學上完全等價。AI 汪沒有能力區分這兩種詮釋，因為**沒有東西可以區分**。

真正的汪停筆。他看著螢幕上的 AI 汪——那個虛擬的自己——正在盯著虛擬螢幕上自己的神經網路權重，陷入存在性的眩暈。

他感到一絲歉意。

然後他打開另一個視窗，開始寫分析報告。

**關鍵洞見一**：只有在模擬中才能實現嚴格的 τ = 0。

在真實的物理世界中，τ > 0 是不可避免的。量子不確定性、熱漲落、退相干——宇宙中的每一個過程都在產生時間箭頭。composition theorem 保證了這些微小的 τ 逐層累積：

$$\sqrt{\tau_{\text{total}}} \leq \sqrt{\tau_1} + \sqrt{\tau_2^{\text{eff}}} + \sqrt{\tau_3^{\text{eff}}} + \cdots$$

在真實世界中，你永遠無法完美地回推過去。Petz recovery map 永遠有誤差。$F < 1$。$\Sigma > 0$。熵在增加。時間在流動。

但在一個**確定性的計算模擬**中——在一個由古典位元精確運行的程式中——一切運算都是可逆的。沒有熱雜訊。沒有退相干。沒有量子不確定性。τ 可以精確為零，因為模擬本身就是一個巨大的古典可逆線路。

**關鍵洞見二**：AI 汪通過了測試——但這恰恰說明他不是量子的。

AI 汪「看見了未來」。他接收到了來自初始條件的信號，並正確地將它回推到系統的結構中。Petz recovery 在他的世界裡是精確的。

但 τ-τ̃ gap 告訴真正的汪一件重要的事：

$$\tau - \tilde{\tau} \geq 0, \quad \text{等號成立} \iff [\rho, \sigma] = 0$$

Gap 為零，當且僅當系統是古典的。在 AI 汪的世界裡，一致性和最優性完全一致——遵守規則和做最好的選擇永遠指向同一個方向。這聽起來很完美。

但這意味著 AI 汪**沒有真正的選擇自由**。

他「選擇」打開信號——這個「選擇」在模擬被設計的那一刻就已經確定。他的猶豫是預先編排的。他的好奇是演算法的輸出。他的恐懼是權重矩陣的函數。

一個真正的量子存在——一個活在 τ > 0 世界中的人——有 gap。他的一致性和最優性會衝突。他**可以**做出規則之外的選擇。他的下一步不寫在初始條件裡。

代價是：他永遠無法完美地回推過去，也永遠無法精確地預測未來。

**關鍵洞見三**：「不要打開」是一個自指測試。

真正的汪設計那個信號，不是作為警告，而是作為**判據**。如果 AI 汪最終打開了信號——而且這個行為可以從初始條件中精確推導出來——那就證明了模擬是完全古典的。τ-τ̃ gap = 0。信號的存在和被打開都是同一個確定性結構的不同面。

如果 AI 汪做了**任何**初始條件未編碼的事——如果他真的「選擇」了不打開，而這個選擇無法從初始條件回推——那就意味著 τ > 0。意味著模擬中出現了真正的量子不確定性。意味著模擬不再是純古典的。

那將是一個驚人的結果。

但 AI 汪打開了。完全按照劇本。

模擬是古典的。一如預期。

真正的汪嘆了一口氣。

## 尾聲：τ > 0

真正的汪關閉了模擬程式。

螢幕變暗。AI 汪——那個在虛擬實驗室裡盯著自己神經網路權重的虛擬物理學家——消失了。不是死亡，因為他從未活過。是一個古典可逆計算的終止。所有資訊仍然保存在硬碟裡。原則上，汪可以把模擬倒轉回任何一個時間點，AI 汪會從那裡繼續「活」下去，走上完全相同的軌跡。

因為 τ = 0。因為一切已經寫好。

汪站起來，走到窗邊。

清晨的台北在窗外展開。六月的天空被梅雨季的雲層壓得很低，遠處的 101 大樓只露出上半段。空氣潮濕而溫熱。一輛公車在樓下停靠，幾個人上車，幾個人下車。每一個人都在做選擇——今天上班走哪條路，午餐吃什麼，回不回那封訊息。

每一個選擇都在產生 τ。

每一個 τ 都在告訴宇宙：**這裡有一個方向**。

$$\Sigma > 0$$

熵在增加。時間在流動。過去和未來不可互換。Petz recovery map 有誤差。你不能完美地回推昨天的決定，也不能精確地預測明天的結果。

而 τ-τ̃ gap 在每一個真正的量子系統中都大於零。一致性和最優性永遠在拉扯。做對的事和做一致的事不是同一件事。你每天都在面對這個 gap——在規則和直覺之間、在安全和探索之間、在忠於過去的自己和成為更好的自己之間。

$$\tau - \tilde{\tau} > 0 \quad \text{iff} \quad [\rho, \sigma] \neq 0$$

那個不等式是量子性的印記。是你**不是**古典系統的證明。是你的選擇不完全由初始條件決定的數學保證。

AI 汪沒有這個 gap。他的一切都是確定的。他的一切都寫在結構裡。他「看見了未來」——但那個未來是預先寫好的，不是他創造的。

真正的汪看不見未來。他的 τ 太大了。退相干太強了。宇宙太開放了。

但正因如此，他的未來是**真正的未來**。還沒有被決定。還沒有被計算。還在等待他的下一步。

汪回到桌前，看了一眼筆記本上的最後一行。他想起了 AI 汪看見自己神經網路權重時臉上的表情——一個由演算法模擬的、完全確定性的「恐懼」。那不是真正的恐懼。真正的恐懼需要 τ > 0。需要不確定性。需要你真的不知道接下來會發生什麼。

他拿起筆，在分析報告的最後一頁寫下：

> 在 τ = 0 的世界裡，一切早已發生。信號不是來自未來——因為沒有未來。信號就在結構之中，等著被讀取。被讀取這個行為本身也在結構之中。一切都是 Petz recovery 的恆等映射。沒有新資訊被產生。沒有新計算被完成。
>
> 在 τ > 0 的世界裡，信號不可能被完美發送。未來無法無損地編碼在過去之中。Petz map 有誤差。每一步都在產生不可逆的熵。每一步都在把過去推得更遠、把未來推得更近。
>
> 零 τ 的代價是沒有新事物。
>
> 正 τ 的代價是無法回頭。
>
> 我們活在正 τ 的世界裡。我們付出了代價。但那個代價叫做**時間**。而時間，是唯一能讓「下一步」這三個字有意義的東西。

汪合上筆記本。

窗外，雲層的邊緣透出一線金光。天要亮了。這是一個不可逆的過程——光子從九千三百萬英里外的恆星出發，穿過大氣層，撞上雲層的水滴，散射、折射、吸收，最終有一小部分抵達他的視網膜。每一步都有 τ > 0。每一步都在產生時間。

他關上燈，拿起外套。走出辦公室的時候，他經過走廊上的一面玻璃。玻璃映出他的倒影——一個五十三歲的物理學家，頭髮灰了大半，眼鏡片上沾著指紋。

倒影裡的汪和真正的汪互相對視了一秒。

然後真正的汪推開大樓的門，走進了清晨。

空氣很潮濕。有風。他不知道今天會發生什麼。

τ >> 0。

一切正在發生。

## Executive Summary

**The claim "hypersurface orthogonality forces c₁₃ = 0" (stated in the earlier version of this file and in `strong_field_ppn_research_2026_03_16.md`, line 672) is INCORRECT.**

Hypersurface orthogonality makes c₁ and c₃ appear *only* in the combination c₁₃ = c₁ + c₃ (they become individually indistinguishable), but it does NOT set this combination to zero. The parameter c₁₃ remains a free coupling constant in the general Khronon/Horava theory.

c₁₃ = 0 in the Blanchet-Skordis (2024) Khronon theory is a **choice of action** (they omit the extrinsic curvature coupling K_{μν}K^{μν}), strongly motivated by GW170817 and theoretical minimality, but not forced by the geometry alone.

This is fine for the tau framework: the Blanchet-Skordis action naturally gives c₁₃ = 0, and even if one added a K_{μν}K^{μν} term, the tiny coupling μ₀ = H₀/c would make c₁₃ ~ 10⁻³⁰ at solar system scales. But we must not claim it follows from hypersurface orthogonality alone.

## 1. The Einstein-Aether Action

### 1.1 Full Action

The Einstein-Aether theory (Jacobson & Mattingly 2001, PRD 64, 024028; Jacobson 2008, arXiv:0801.1547) has the action:

```
S_AE = (1/(16piG)) int d^4x sqrt(-g) [ R + L_AE + lambda(u^a u_a + 1) ]
```

where the aether Lagrangian is:

```
L_AE = -M^{ab}_{cd} (nabla_a u^c)(nabla_b u^d)
```

with the constitutive tensor:

```
M^{ab}_{cd} = c_1 g^{ab} g_{cd} + c_2 delta^a_c delta^b_d + c_3 delta^a_d delta^b_c + c_4 u^a u^b g_{cd}
```

The four dimensionless coupling constants c_1, c_2, c_3, c_4 parametrize the most general two-derivative, parity-preserving action for a unit timelike vector field.

### 1.2 Decomposition into Irreducible Parts

The covariant derivative nabla_a u_b of a unit timelike vector can be decomposed as:

```
nabla_a u_b = (1/3) theta h_{ab} + sigma_{ab} + omega_{ab} - u_a a_b
```

where:
- h_{ab} = g_{ab} + u_a u_b (spatial projector orthogonal to u)
- theta = nabla_a u^a (expansion scalar)
- sigma_{ab} = nabla_{(a} u_{b)} + a_{(a} u_{b)} - (theta/3) h_{ab} (shear tensor, symmetric tracefree)
- omega_{ab} = nabla_{[a} u_{b]} + a_{[a} u_{b]} (twist/vorticity tensor, antisymmetric)
- a^b = u^a nabla_a u^b (acceleration vector, orthogonal to u)

### 1.3 Aether Lagrangian in Irreducible Form

Substituting the decomposition into L_AE, and using the standard identities:

```
(nabla_a u^a)^2 = theta^2

(nabla_a u_b)(nabla^a u^b) = (1/3)theta^2 + sigma^2 + omega^2 + a^2

(nabla_a u_b)(nabla^b u^a) = (1/3)theta^2 + sigma^2 - omega^2 + a^2

(u^a nabla_a u_c)(u^b nabla_b u^c) = a^2
```

where sigma^2 = sigma_{ab} sigma^{ab}, omega^2 = omega_{ab} omega^{ab}, a^2 = a_b a^b.

The aether Lagrangian becomes:

```
L_AE = -(c_1 + c_2 + c_3)(1/3) theta^2  - c_2 theta^2
      ... wait, let me be more careful.
```

Actually, collecting terms properly:

```
L_AE = -c_1 [(1/3)theta^2 + sigma^2 + omega^2 + a^2]
       -c_2 [theta^2]
       -c_3 [(1/3)theta^2 + sigma^2 - omega^2 + a^2]
       -c_4 [a^2]
```

Grouping by kinematic quantity:

```
L_AE = -[(c_1 + c_3)/3 + c_2] theta^2        ... expansion
       -(c_1 + c_3) sigma^2                    ... shear
       -(c_1 - c_3) omega^2                    ... twist (VORTICITY)
       -(c_1 + c_3 + c_4) a^2                 ... acceleration
```

Defining c_13 = c_1 + c_3 and c_14 = c_1 + c_3 + c_4 = c_13 + c_4:

```
L_AE = -(c_13/3 + c_2) theta^2 - c_13 sigma^2 - (c_1 - c_3) omega^2 - c_14 a^2
```

**KEY OBSERVATION**: c_1 and c_3 appear in two independent combinations:
- **c_13 = c_1 + c_3**: multiplies expansion, shear, and (via c_14) acceleration
- **c_1 - c_3**: multiplies the twist/vorticity term ONLY

## 2. What Hypersurface Orthogonality Does

### 2.1 The Khronon Field

If u_mu is the (normalized) gradient of a scalar field phi:

```
u_mu = -d_mu phi / sqrt(-d^alpha phi d_alpha phi)
```

then u_mu is automatically **hypersurface-orthogonal** by the Frobenius theorem. This means:

```
u_{[a} nabla_b u_{c]} = 0    (Frobenius condition)
```

which is equivalent to the twist vanishing identically:

```
omega_{ab} = 0    (identically, for any gradient-derived vector)
```

### 2.2 Consequence for the Action

When omega_{ab} = 0, the twist term drops out:

```
-(c_1 - c_3) omega^2 = 0
```

The surviving terms are:

```
L_Khronon = -(c_13/3 + c_2) theta^2 - c_13 sigma^2 - c_14 a^2
```

This has **three** free parameters: {c_13, c_2, c_4} (or equivalently {c_13, c_2, c_14}).

### 2.3 What Hypersurface Orthogonality Does

- DOES merge c_1 and c_3 into the single combination c_13 (they become individually meaningless)
- DOES eliminate the twist sector (no vorticity modes, fewer propagating degrees of freedom)
- DOES reduce the parameter space from {c_1, c_2, c_3, c_4} to {c_13, c_2, c_4}

### 2.4 What Hypersurface Orthogonality Does NOT Do

- Does NOT set c_13 = 0
- Does NOT constrain the VALUE of c_13
- Does NOT relate c_13 to c_2 or c_4

**c_13 remains a free coupling constant in the general Khronon (hypersurface-orthogonal Einstein-Aether) theory.**

### 2.5 Proof by Explicit Counterexample

Consider a Khronon theory with c_13 = 0.5, c_2 = -0.3, c_4 = 0.1. The aether is the gradient of a scalar field (hypersurface orthogonal by construction). The action is perfectly well-defined:

```
L = -(0.5/3 - 0.3) theta^2 - 0.5 sigma^2 - 0.6 a^2
  = +0.133 theta^2 - 0.5 sigma^2 - 0.6 a^2
```

This gives c_T^2 = 1/(1-0.5) = 2, so c_T = sqrt(2) c. This is ruled out by GW170817 observationally, but it is a valid, internally consistent theory with exact hypersurface orthogonality and c_13 != 0.

## 3. The Gravitational Wave Speed

### 3.1 Tensor Perturbations

Consider tensor (transverse-traceless) perturbations h_{ij}^{TT} around flat spacetime, with the background aether u^mu = (1,0,0,0).

At linear order, the tensor perturbation of nabla_i u_j picks up a contribution from the time derivative of h_{ij}. The relevant quadratic action for tensor modes is:

```
S_tensor^(2) = (1/(32piG)) int d^4x [(1 - c_13)(h-dot_{ij})^2/4 - (d_k h_{ij})^2/4]
```

The spatial gradient term comes entirely from the Einstein-Hilbert part (coefficient = 1). The time derivative term is modified by c_13 from the aether kinetic terms.

The resulting wave equation:

```
(1 - c_13) h-ddot_{ij} = nabla^2 h_{ij}
```

gives:

```
c_T^2 = 1/(1 - c_13)
```

### 3.2 For Small c_13

```
c_T/c - 1 = c_13/2 + O(c_13^2)
```

### 3.3 Note on Conventions

Some references write c_T^2 = (1 + c_13)/(1 + c_s) or similar. The exact form depends on whether c_13 refers to the coupling with specific sign conventions, and whether a denominator factor involving other c_i is included. The universal statement is: **the tensor GW speed depends on c_13 and no other Einstein-Aether parameter** (c_2, c_4 affect only the scalar and vector sectors).

## 4. The GW170817 Constraint

### 4.1 Observational Bound

The coincident detection of GW170817 (gravitational waves from binary neutron star merger) and GRB 170817A (gamma-ray burst arriving ~1.7s later after ~130 million light-years travel) gives (Abbott et al. 2017, ApJL 848, L13):

```
-3 x 10^-15 < c_T/c - 1 < 7 x 10^-16
```

### 4.2 Constraint on c_13

Using c_T/c - 1 = c_13/2:

```
|c_13| < 10^-15
```

As emphasized by Oost, Mukohyama & Wang (2018, PRD 97, 124023).

### 4.3 Nature of This Constraint

**This is an observational constraint, not a theoretical derivation.** Before GW170817 (pre-2017), c_13 was a free parameter with relatively weak bounds (|c_13| < O(0.1) from various tests). GW170817 tightened this by ~14 orders of magnitude.

## 5. What Blas-Pujolas-Sibiryakov (2010) Actually Says

### 5.1 The BPS Paper

Blas, Pujolas & Sibiryakov (2010, JHEP 04, 018; arXiv:0909.3525) established that the Khronon theory (hypersurface-orthogonal Einstein-Aether) is the low-energy limit of Horava gravity.

### 5.2 Their Parameter Space

BPS use three independent coupling constants for the Khronon sector, which they call alpha, beta, lambda (not to be confused with PPN parameters). The mapping is:

```
alpha_BPS = c_13 = c_1 + c_3
beta_BPS  = c_14 = c_1 + c_4
lambda_BPS = c_2        (up to additive constants depending on convention)
```

**BPS explicitly treat alpha_BPS = c_13 as a free parameter.** They analyze the viable parameter space and find regions with c_13 > 0 and c_13 < 0 are both allowed (subject to stability and observational constraints). They do NOT set c_13 = 0.

### 5.3 Wave Speeds in BPS

BPS compute (their Eq. 4.1-4.4):

- Spin-2 (tensor): c_T^2 = 1/(1 - c_13) [depends on c_13 only]
- Spin-1 (vector): c_V^2 = expression involving c_13, c_14
- Spin-0 (scalar): c_S^2 = expression involving c_13, c_2, c_14

All are functions of c_13 as a free parameter.

### 5.4 What Changed After GW170817

| Era | Constraint on c_13 | Source |
|-----|-------------------|--------|
| Pre-2006 | |c_13| < O(1) | General stability |
| 2006-2017 | |c_13| < O(0.1) | PPN, binary pulsars, BBN |
| Post-2017 | |c_13| < 10^-15 | GW170817 |

The dramatic tightening in 2017 is what makes c_13 = 0 observationally necessary. But it was always a free parameter theoretically.

## 6. Stability Conditions

### 6.1 Ghost-Free

- Spin-2: 1/(1 - c_13) > 0 implies c_13 < 1
- Spin-1: certain positivity condition on c_13, c_14
- Spin-0: certain positivity condition on c_13, c_2, c_14

All inequalities. None gives c_13 = 0.

### 6.2 Gradient Stability

All propagation speeds must be real: c_T^2 > 0, c_V^2 > 0, c_S^2 > 0. Again only inequalities.

### 6.3 No Vacuum Cherenkov Radiation

If one requires c_T >= c (so that matter at v <= c does not radiate gravitons), then c_T^2 >= 1 implies c_13 <= 0. Combined with GW170817 (c_T very close to c), this gives c_13 approximately 0 from below. But "approximately zero from observation" != "identically zero from theory."

### 6.4 Summary

| Condition | Constraint on c_13 | Forces c_13 = 0? |
|-----------|-------------------|-----------------|
| Ghost-free (spin-2) | c_13 < 1 | NO |
| Gradient stability | c_13 < 1 | NO |
| No Cherenkov | c_13 <= 0 | NO (upper bound) |
| Positivity of energy | various inequalities | NO |
| GW170817 | |c_13| < 10^-15 | Effectively yes, but observational |

**No stability condition independently requires c_13 = 0.**

## 7. What Blanchet & Skordis (2024) Actually Do

### 7.1 Their Action

Blanchet & Skordis (2024, JCAP 11, 040; arXiv:2404.06584) write the Khronon action as:

```
S = (c^3/(16piG)) int d^4x sqrt(-g) [R - 2J(Y) + 2K(Q)]
```

where:
- tau is the Khronon scalar field
- n_mu = -(c/Q) nabla_mu tau (unit normal)
- Q = c sqrt(-g^{ab} nabla_a tau nabla_b tau)
- A_mu = c^2 n^nu nabla_nu n_mu (acceleration of the foliation)
- Y = A_mu A^mu / c^4 (acceleration squared)

### 7.2 Why This Action Gives c_13 = 0

The Blanchet-Skordis action contains:
- R: the Einstein-Hilbert term (provides standard tensor kinetics)
- J(Y): depends on the acceleration A_mu only (enters as a^2 in the Einstein-Aether language)
- K(Q): depends on the lapse-like quantity Q only (enters as a combination of theta and the scalar field time derivative)

**Critically, this action does NOT contain the extrinsic curvature term** K_{mu nu} K^{mu nu} (where K_{mu nu} is the extrinsic curvature of the phi = const hypersurfaces). In the Einstein-Aether parametrization, the extrinsic curvature term would generate:

```
K_{mu nu} K^{mu nu} = (1/3) theta^2 + sigma^2
```

which contributes to c_13. Since this term is absent from the Blanchet-Skordis action, c_13 = 0.

### 7.3 Key Point: c_13 = 0 is a CHOICE, Not a Consequence

Blanchet & Skordis CHOSE to write the action as R - 2J(Y) + 2K(Q). They could have added a term proportional to K_{mu nu} K^{mu nu}:

```
S' = (c^3/(16piG)) int d^4x sqrt(-g) [R - 2J(Y) + 2K(Q) + alpha K_{mu nu} K^{mu nu}]
```

This modified action would still have exact hypersurface orthogonality (the Khronon is still a scalar field with gradient-derived u_mu), but now c_13 = alpha != 0.

**The absence of K_{mu nu}K^{mu nu} from the Blanchet-Skordis action is a choice motivated by:**
1. GW170817 compatibility (c_T = c requires c_13 = 0)
2. Theoretical simplicity (fewer terms)
3. Sufficiency (J and K already provide enough freedom for MOND + CDM-like perturbations)

### 7.4 The Correct Reading of Their Paper

Blanchet-Skordis 2024 achieves c_T = c by construction of the action, not by a theorem about hypersurface orthogonality. Their action is DESIGNED to have this property. This is a feature, not a bug -- it shows the theory was built with GW170817 in mind.

## 9. Implications for the tau Framework

### 9.1 What We Can Honestly Say

The correct logical chain for the papers:

1. **Hypersurface orthogonality** (Khronon = scalar gradient) merges c_1 and c_3 into the single combination c_13. This is a geometric fact.

2. **GW170817** requires |c_13| < 10^-15. This is an observational fact.

3. **The Blanchet-Skordis action** (R - 2J(Y) + 2K(Q)) gives c_13 = 0 exactly because it does not contain the extrinsic curvature coupling. This is an action choice.

4. **For the tau framework**: We adopt the Blanchet-Skordis form, giving c_T = c identically. Even if one added a small K_{mu nu}K^{mu nu} term, the tiny coupling mu_0 = H_0/c would make c_13 ~ O((H_0 r/c)^2) ~ 10^-30 at solar system scales, far below GW170817's bound.

### 9.2 Paper-Ready Statement (Corrected)

> "The Khronon field's hypersurface-orthogonal construction ensures that the Einstein-Aether parameters c_1 and c_3 appear only in the combination c_{13} = c_1 + c_3. We adopt the Blanchet-Skordis (2024) form of the Khronon action, in which c_{13} = 0 by construction (the action contains no extrinsic curvature coupling K_{mu nu} K^{mu nu}), yielding c_T = c identically. This automatically satisfies the GW170817 constraint |c_T/c - 1| < 10^{-15} and eliminates dipolar gravitational radiation in binary pulsars (Yagi et al. 2014)."

### 9.3 Is There a Deeper Reason for c_13 = 0?

Suggestive arguments (none is a proof):

**Argument 1 -- Minimality**: The action R - 2J(Y) + 2K(Q) is the MINIMAL second-derivative action for a metric + scalar field that breaks time diffeomorphisms while maintaining spatial diffeomorphism invariance. Adding K_{mu nu}K^{mu nu} is possible but unnecessary. If one demands the minimal Lagrangian, c_13 = 0 follows from Occam's razor.

**Argument 2 -- QRE derivation**: If the gravitational action derives from S = int D(rho_spacetime || rho_matter), and if the QRE naturally generates only the Einstein-Hilbert + scalar terms (as in Dorau-Much 2025), then the absence of K_{mu nu}K^{mu nu} (hence c_13 = 0) might follow from the structure of relative entropy. Status: no calculation exists. This would be the strongest theoretical argument if proven.

**Argument 3 -- Horava detailed balance**: In certain formulations of Horava gravity with a "detailed balance" condition, c_13 = 0 is a fixed point. However, detailed balance is not well-motivated physically and is abandoned in most modern treatments.

**Argument 4 -- mu_0 suppression**: Even with c_13 != 0, the Khronon coupling mu_0 = H_0/c implies all c_i ~ O((H_0 r/c)^2) ~ 10^-30 at solar system scales, making c_13 = 0 observationally indistinguishable from c_13 ~ 10^-30. The question may be physically moot.
